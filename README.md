신입사원 온보딩 자동화 프로그램

Employee Onboarding Automation

신입사원이 입사했을 때
“누가, 무엇을, 언제까지 준비해야 하는지” 자동으로 정리하고 관리하는 프로그램입니다.

1. 왜 만들었나요?

신입사원 한 명이 입사하면 생각보다 많은 준비가 필요합니다.

예를 들어,

근로계약서 작성

노트북 준비

회사 이메일 계정 생성

사원증 발급

보안서약 확인

필수교육 안내

부서 교육

각종 서류 제출

같은 업무가 발생합니다.

문제는 이 일을 한 사람이 전부 처리하지 않는다는 점입니다.

해야 할 일

담당

근로계약서

인사담당자

노트북 준비

IT 담당자

부서 교육

부서장

보안 관련 확인

보안 담당자

신입사원이 많아질수록 다음과 같은 확인 업무도 늘어납니다.

“노트북 신청했나요?”
“교육은 누가 담당하나요?”
“서류가 아직 안 들어왔는데요?”
“이 업무는 누가 해야 하죠?”

이 프로그램은 이런 반복 확인과 누락을 줄이기 위해 만들었습니다.

2. 쉽게 설명하면

신입사원을 등록하면 프로그램이 다음 순서로 관리합니다.

신입사원 등록
      ↓
부서 / 직무 확인
      ↓
필요한 온보딩 업무 생성
      ↓
담당자 배정
      ↓
업무별 마감일 계산
      ↓
진행상태 확인
      ↓
지연 업무 확인
      ↓
온보딩 완료

쉽게 말하면,

“신입사원 입사 준비용 자동 체크리스트 + 업무관리 프로그램”

입니다.

3. 주요 기능

① 신입사원 관리

신입사원의 기본 정보를 등록하고 관리할 수 있습니다.

예:

이름

소속부서

직무

고용형태

입사일

상태

입사예정자와 재직 상태를 구분해 관리할 수 있습니다.

② 온보딩 템플릿 관리

모든 직원에게 똑같은 준비가 필요한 것은 아닙니다.

예를 들어 개발직은:

노트북 준비
개발계정 생성
개발환경 설정
보안교육
부서교육

영업직은:

노트북 준비
법인카드 신청
CRM 계정 생성
제품교육
영업교육

처럼 직무와 부서에 따라 다른 온보딩 절차를 만들 수 있습니다.

③ 입사자별 업무 자동 생성

신입사원을 등록하면 선택된 템플릿을 기준으로 필요한 업무가 생성됩니다.

예:

홍길동
입사일 : 2026-09-01

입사 7일 전 → 노트북 신청
입사 3일 전 → 계정 생성
입사 당일   → 근로계약 확인
입사 후 3일 → 보안교육
입사 후 7일 → 부서교육 확인

④ 담당자 관리

업무마다 담당자를 지정할 수 있습니다.

예:

노트북       → IT
근로계약서   → 인사
부서교육     → 부서장
보안교육     → 보안 담당자

그래서 “이 업무는 누가 해야 하지?”라는 문제를 줄일 수 있습니다.

⑤ 마감일 및 지연 업무 관리

각 업무의 기한과 진행상태를 관리합니다.

✅ 완료
🕐 진행중
⚠️ 지연
🚫 취소

기한이 지난 업무를 한눈에 확인할 수 있습니다.

4. 대시보드

대시보드에서는 전체 온보딩 상황을 한눈에 확인할 수 있습니다.

예:

등록된 입사자     8명
입사 예정         3명
진행중            4명
지연 업무         5건

여러 신입사원의 상황을 하나씩 확인하지 않아도 전체 진행상태를 빠르게 파악할 수 있습니다.

5. 개별 입사자 진행상태

입사자 한 명을 선택하면 해당 직원에게 필요한 업무를 확인할 수 있습니다.

예:

홍길동 / 개발팀

✅ 노트북 준비
✅ 이메일 계정
✅ 근로계약
🕐 보안교육
⚠️ 부서교육

필요하면 개별 업무를 추가하거나 수정할 수도 있습니다.

6. 예외 상황 처리

실제 회사에서는 계획대로만 일이 진행되지 않습니다.

예를 들어,

입사일 변경

담당자 변경

업무 취소

추가 업무 발생

부서 변경

같은 상황이 생길 수 있습니다.

이 프로그램은 단순 체크리스트가 아니라 이런 예외 상황도 관리할 수 있도록 설계했습니다.

7. 문서 관리

온보딩 과정에서 필요한 문서를 관리할 수 있습니다.

예:

근로계약서

개인정보 동의서

보안서약서

각종 제출서류

문서 상태도 관리할 수 있습니다.

미제출
제출
확인완료
보완요청

8. Excel 자료 관리

온보딩 데이터를 Excel로 내보내거나 관리할 수 있도록 구성했습니다.

이를 통해:

데이터를 별도로 보관하고

업무 현황을 공유하고

추가 분석에 활용

할 수 있습니다.

9. 코드 없이 설정 변경

이 프로젝트에서 중요하게 생각한 부분입니다.

회사마다 사용하는 용어와 업무 방식이 다르기 때문에 가능한 설정은 프로그램 안에서 변경할 수 있도록 설계했습니다.

예:

프로그램 이름
메뉴 이름
업무 이름
온보딩 항목
담당부서
업무 순서
필수 / 권장 여부
기한
사용 여부

즉,

단순히 개발자가 만든 고정 프로그램이 아니라
회사의 업무 방식에 맞게 운영자가 수정할 수 있는 프로그램

을 목표로 했습니다.

10. 사용 방법

Windows 기준

STEP 1. 저장소 다운로드

GitHub 화면에서:

Code → Download ZIP

을 선택합니다.

STEP 2. 압축 해제

다운로드한 ZIP 파일의 압축을 풉니다.

STEP 3. Python 확인

Python 3.11 이상 사용을 권장합니다.

STEP 4. 프로그램 실행

폴더 안의:

run.bat

파일을 실행합니다.

필요한 Python 패키지를 설치한 뒤 프로그램이 실행됩니다.

11. 직접 실행하는 방법

터미널에서 다음 명령어를 실행합니다.

pip install -r requirements.txt

그다음:

uvicorn main:app --reload

을 실행합니다.

브라우저에서 아래 주소로 접속합니다.

http://127.0.0.1:8000

14. 이 프로젝트에서 중요하게 생각한 점

일반적인 체크리스트는:

할 일 작성
→ 체크
→ 끝

입니다.

이 프로젝트는:

입사자 등록
→ 조건 확인
→ 업무 생성
→ 담당자 배정
→ 기한 관리
→ 진행상태 확인
→ 지연업무 확인
→ 예외 처리
→ 결과 기록

까지 연결하려고 했습니다.

즉, 단순 체크리스트가 아니라 실제 업무 흐름을 관리하는 시스템을 목표로 했습니다.

15. 업무 프로세스 분석

신입사원 입사 과정에서 발생하는 반복 업무와 누락 가능성을 분석했습니다.

업무 자동화

반복되는 업무 생성과 기한 관리를 자동화했습니다.

사용자 편의성

개발자가 코드를 수정하지 않아도 운영자가 프로그램 안에서 설정을 변경할 수 있도록 설계했습니다.

예외 상황 고려

입사일 변경, 담당자 변경, 업무 취소 등 실제 회사에서 발생할 수 있는 상황을 고려했습니다.

데이터 관리

입사자별 진행상태와 업무 처리정보를 데이터로 관리할 수 있도록 구성했습니다.

16. 프로젝트 핵심 메시지

이 프로젝트의 목적은:

“신입사원 입사 준비를 사람이 기억해서 관리하는 방식에서, 시스템이 업무를 만들어주고 사람이 확인하는 방식으로 바꾸는 것”

입니다.

자동화의 목적은 사람을 없애는 것이 아니라,

사람이 반복 확인에 사용하는 시간을 줄이고 중요한 업무에 집중하도록 돕는 것

이라고 생각했습니다.

18. 현재 한계

이 프로젝트는 완성된 상용 HR 시스템이 아니라 포트폴리오용 프로토타입/MVP입니다.

현재 버전에는 실제 기업용으로 필요한 다음 기능이 완전히 구현되어 있지 않습니다.

실제 사내 계정 로그인 / SSO

실제 사용자별 권한 인증

Outlook / Teams / 사내 메신저 자동 알림

실제 HRIS 연동

실제 전자결재 연동

실제 계정 자동 발급

실제 전자서명 서비스 연동

이 기능들은 실제 회사 시스템과 API가 있어야 연동할 수 있기 때문에 현재 버전에서는 제외했습니다.

마무리

신입사원 온보딩은 단순히 체크리스트를 작성하는 일이 아니라,

사람, 부서, 일정, 문서, 업무를 연결해서 빠진 것이 없도록 관리하는 과정입니다.

이 프로젝트는 그 과정을 하나의 프로그램으로 정리하고 자동화해 보기 위해 제작했습니다.
